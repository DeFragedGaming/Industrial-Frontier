INDUSTRIAL FRONTIER
Development Showcase v3
Windows x64

FIRST-PERSON GAMEPLAY UPDATE

Controls:
WASD - Move
Mouse - Look
Shift - Sprint
Space - Jump
Left Click - Capture mouse
Escape - Release mouse / Exit

Launch:
Run IndustrialFrontier.exe

Current Features:
- First-person camera
- Procedural terrain
- Background terrain generation
- Dynamic terrain streaming
- Player movement and jumping
- OpenGL shader-based terrain rendering

This is an early development showcase.
Mining, inventory, machinery, and automation are planned
for future development.
